# Trabalho-MULTICIPLINAR-1-D-
Atividade Multidisciplinar – 3º TrimestreComponentes Curriculares: Ciência de Dados & Técnicas Integradas em IA   
1. O que são Dados de Treinamento?Os dados de treinamento funcionam como o combustível de qualquer modelo de Inteligência Artificial. São os conjuntos de informações — como imagens, áudios, textos ou tabelas numéricas — que a máquina analisa para identificar padrões e aprender a realizar previsões ou tomadas de decisão. A qualidade e a diversidade desses dados determinam a capacidade do sistema em resolver problemas no mundo real com precisão.   
2. Viés em Inteligência ArtificialO viés estatístico e ético surge quando a base de dados utilizada no treinamento contém distorções, lacunas ou preconceitos históricos. Se um modelo for alimentado com amostras desequilibradas, ele repetirá e ampliará essas falhas em suas previsões. Como os algoritmos não possuem consciência ética, cabe ao desenvolvedor auditar a base para evitar diagnósticos injustos ou discriminatórios.   
3. Overfitting (Superajuste do Modelo)O overfitting é uma falha de generalização que ocorre quando a IA decora os dados de treino em vez de aprender a lógica subjacente do problema. É o equivalente a um estudante que decora um gabarito específico, mas erra ao se deparar com uma questão inédita. Para evitar esse erro, é fundamental validar o modelo com um conjunto de dados inédito durante a etapa de testes.   
4. Algoritmos de Recomendação e Bolhas DigitaisOs sistemas de recomendação analisam continuamente as variáveis de entrada do utilizador ($X$), como tempo de retenção, cliques e horários de acesso, para prever o próximo conteúdo com maior probabilidade de engajamento ($y$). O uso contínuo dessa otimização sem restrições pode confinar o utilizador em uma "bolha digital", isolando-o de perspectivas diversas e limitando sua visão de mundo.   
5. Governança, Privacidade e GuardrailsA proteção de dados exige a remoção e anonimização de informações sensíveis antes do treinamento de qualquer modelo. Além da privacidade, a aplicação de guardrails — regras e travas de segurança programadas no prompt — garante que a IA atue dentro de limites éticos, impedindo a geração de conteúdos falsos, ofensivos ou perigosos.   
6. O Futuro e o Impacto Social da IAA Inteligência Artificial transformará áreas estratégicas como diagnóstico médico, educação personalizada e automação no mercado de trabalho. Contudo, o avanço tecnológico deve vir acompanhado de responsabilidade técnica: o papel do desenvolvedor é garantir que os sistemas construídos sejam seguros, transparentes e benéficos para toda a sociedade.
